كتالوج مصادر البيانات

مصادر مرشحة للاستخدام؛ راجع الترخيص والتاريخ والتغطية قبل إعادة النشر أو اعتماد الحدود إداريًا.

1. OpenStreetMap / Geofabrik — السودان

بيانات طرق وأماكن ومعالم جغرافية قابلة للتنزيل. التغطية والتفاصيل تختلف حسب المنطقة.

https://download.geofabrik.de/africa/sudan.html

OSM / ODbL راجع متطلبات الإسناد والترخيص.

2. geoBoundaries — حدود إدارية

يوفر حدودًا إدارية مفتوحة بمستويات مختلفة. لا تفترض أنها الحدود القانونية المعتمدة دون تحقق.

https://www.geoboundaries.org/

تحقق من مستوى ADM والترخيص

3. Open Admin Data — التقسيمات الإدارية للسودان

مستودع بيانات مجتمعي للتقسيمات الإدارية؛ تحقق من تاريخ الإصدار وطريقة بناء البيانات قبل استخدامها.

مستودع GitHub

4. البوابة الجغرافية السودانية

بوابة محلية محتملة للحصول على بيانات وخدمات جغرافية؛ قد يتطلب الوصول أو الاستخدام شروطًا محددة.

https://geoportal.gov.sd/
هذه قائمة مصادر، وليست شهادة بأن كل البيانات حديثة أو مكتملة أو رسمية. سجّل في ملاحظات كل استيراد: رابط المصدر، تاريخ التنزيل، الترخيص، مستوى الدقة، وما إذا كانت البيانات قد خضعت للتحقق.

عن Sudan GeoVision v0.6

واجهة أولية عربية لإدارة سجلات جغرافية للسودان، مع خريطة تفاعلية وكتالوج مصادر واستيراد وتصدير وفحص جودة أساسي.

  • الخريطة مبنية على Leaflet وتحتاج اتصال إنترنت لتحميل المكتبة وطبقات الخرائط.
  • السجلات تحفظ في تخزين المتصفح (localStorage) على هذا الجهاز والمتصفح فقط.
  • لا توجد قاعدة بيانات مشتركة أو حسابات مستخدمين أو مزامنة خادمية في هذه النسخة.
  • مخطط PostgreSQL/PostGIS المرفق نقطة بداية للتطوير الخادمي وليس قاعدة مستضافة جاهزة.
  • البيانات الإدارية ليست مضمنة تلقائيًا؛ استخدم كتالوج المصادر لاستيراد ملفات تتحقق منها.

التقنيات: HTML, CSS, JavaScript, Leaflet, GeoJSON, CSV, PostgreSQL/PostGIS.
